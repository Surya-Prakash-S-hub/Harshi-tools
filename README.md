# HarshiTools 🛠️

A simple image conversion tool that helps you quickly convert images into different formats.

🌐 Try it here: https://harshi-tools.vercel.app/

## Features

- Convert images quickly
- Supports popular image formats
- Download converted images instantly
- Responsive design
- Light and dark theme support

## Coming Soon

More useful image tools are on the way:

- Batch conversion
- Image compression
- Image resizing
- More image utilities

## About

HarshiTools is a small project built to make image conversion simple and accessible.

This is Version 1, with more improvements and features planned for future updates.
